# ☕ FLEUR LENNY — Repositorio Preuniversitario Oficial
> Plataforma web interactiva, moderna y minimalista con estética pastel inspirada en la comunidad preuniversitaria de Puno (UNAP · CEPREUNA · UNSA · UNMSM).
## 🌸 Características
- 📚 **Biblioteca ** Más de 260 compendios y libros de editoriales líderes (*Lumbreras, Cuzcano, RODO, Uniciencia Sapiens, San Marcos*).
- 🏛️ **Exámenes Reales:** Bancos oficiales de admisión de la **UNAP**, **CEPREUNA**, **UNSA**, **San Marcos (Siglo XXI)**, **RM RACSO** y el **Temario Actualizado UNAP 2026**.
- ⚡ **Formularios:** Fórmulas fijas de Wilson Sadness (Aritmética, Álgebra, Geometría, Trigonometría, Física, Química, Razonamiento Matemático).
