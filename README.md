# ☕ FLEUR LENNY — Repositorio Preuniversitario Oficial

> Plataforma web interactiva, moderna y minimalista con estética pastel inspirada en la comunidad preuniversitaria de Puno y el Altiplano peruano (UNAP · CEPREUNA · UNSA · UNMSM).

---

## 🌸 Características

- 📚 **Biblioteca Curada:** Más de 260 compendios y libros de editoriales líderes (*Lumbreras, Cuzcano, RODO, Uniciencia Sapiens, San Marcos*).
- 🏛️ **Exámenes Reales:** Bancos oficiales de admisión de la **UNAP**, **CEPREUNA**, **UNSA**, **San Marcos (Siglo XXI)**, **RM RACSO** y el **Temario Actualizado UNAP 2026**.
- ⚡ **Formularios Insanos:** Fórmulas fijas de Wilson Sadness (Aritmética, Álgebra, Geometría, Trigonometría, Física, Química, Razonamiento Matemático).
- 🎨 **Estética Pastel Soft:** Paleta cálida y minimalista en tonos moca, crema y durazno, pensada para estudiar cómodamente durante horas.
- ⚡ **100% Frontend Puro:** Cero dependencias pesadas, carga instantánea mediante HTML5, CSS3 y JavaScript Vanilla.

---

## 🚀 Despliegue en GitHub Pages

1. Ve a **Settings** de este repositorio.
2. En la sección **Pages**, selecciona la rama `main` (o `master`) y la carpeta `/ (root)`.
3. ¡Tu web estará disponible al instante en una URL pública gratuita!
